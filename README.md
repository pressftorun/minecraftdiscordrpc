# Присутствие в мире

Клиентский Discord RPC для **Minecraft Java 1.21.11 / Fabric**, Windows.

В Discord отображаются:

- ник игрока (также в главном меню);
- одиночная игра или адрес сервера из подключения (DNS/IP и указанный порт);
- ванильный биом на русском независимо от языка игры;
- измерение: Верхний мир, Незер или Энд;
- время суток: Утро (06:00–12:00), День (12:00–18:00), Вечер (18:00–20:00), Ночь (20:00–06:00);
- таймер текущего сеанса в мире/на сервере.
- статус «В главном меню», когда игрок вне мира (также в настройках и списке серверов).

Пример:

```text
Ник: Steve | Одиночная игра
Биом: Равнины | Измерение: Верхний мир | Время суток: День
Прошло 00:42:15
```

Первые две строки передаются в отдельных полях Discord (`details` и `state`).
Таймер отображается отдельным элементом Discord. В мод встроена сгенерированная
обложка в стиле Paint: она используется как иконка в Mod Menu.
Для биомов и измерений модов используются подписи «Неизвестный биом» и
«Неизвестное измерение». Координаты, здоровье и голод не передаются.

Время сеанса начинается при входе и сбрасывается при выходе. Переход между
измерениями его не сбрасывает. Это реальное время сеанса, включая паузы;
накопленное время прошлых посещений не сохраняется. Статус обновляется раз
в секунду; изменившиеся данные отправляются в Discord при ближайшем опросе IPC
(каждые 100 мс). После выхода из мира статус меняется на «В главном меню»,
без биома, игровых показателей и таймера мира. Меню паузы внутри мира
сохраняет игровой статус.

[Все версии и готовые JAR](https://github.com/pressftorun/minecraftdiscordrpc#версии-и-загрузка)

## Установка

1. Установить Fabric Loader **0.19.5+** для Minecraft **1.21.11** и Fabric API
   **0.141.6+1.21.11**. Для игры нужна Java **21+**.
2. Заменить старый JAR мода на `world-presence-1.5.2+1.21.11.jar` из `build/libs`
   в папке `mods` клиента. Для экрана настроек установить
   [Mod Menu 17.0.1 для 1.21.11](https://modrinth.com/mod/modmenu/version/17.0.1).
3. Запустить игру один раз: появится `config/world-presence.json`.
4. Создать приложение на [Discord Developer Portal](https://discord.com/developers/applications).
   Его название будет названием игры в активности Discord. Скопировать **Application ID**
   из General Information. Открыть **Моды → World Presence → Настроить**,
   вставить ID и нажать **Сохранить**. Мод в списке называется «Присутствие в мире».
   Подключение к Discord переключится
   без перезапуска Minecraft. Пустой ID отключает RPC.

   Перед сохранением можно нажать **Проверить ID**. Мод подключится к настольному
   Discord и дождётся подтверждения Application ID. Результат появится под кнопкой:
   принят, отклонён (с кодом Discord), Discord недоступен или не ответил за 10 секунд.
   Проверка не сохраняет ID и не публикует тестовый статус. При изменении ID или
   закрытии настроек проверка отменяется. Подтверждение подключения не проверяет
   настройки видимости активности в Discord.

   Вместо Mod Menu можно записать ID в конфиг перед запуском игры:

   ```json
   { "applicationId": "ВАШ_APPLICATION_ID" }
   ```

5. Открыть настольный Discord: активность появляется уже в главном меню игры.
   В Discord включить отображение текущей активности в настройках конфиденциальности активности.

Для картинки в Discord откройте то же приложение в Developer Portal →
**Rich Presence → Art Assets**, загрузите `assets/rpc-cover-paint.png` и задайте
имя ресурса **rpc_cover**. Мод запрашивает его и в главном меню, и в мире.
Значок в разделе «Общая информация» и иконка Mod Menu задаются отдельно от
крупной картинки RPC. Без ресурса `rpc_cover` картинка в активности не появится.

Токен бота, Client Secret и авторизация пользователя не нужны.
На сервер устанавливать мод не требуется. Адрес сервера будет виден людям,
которые видят вашу активность Discord. Discord в браузере не поддерживается.
Если Discord закрыт, мод повторяет подключение в фоне. После разрыва связи
восстановление может занять до 30 секунд.

## Сборка

Установить JDK 25 для запуска Gradle и JDK 21 для компиляции и игры.
В `JAVA_HOME` указать JDK 25; Gradle выбирает JDK 21 через Java toolchain. Выполнить:

```powershell
.\gradlew.bat build
```

`build` проверяет форматирование, валидацию ID, сохранение конфига и статус
главного меню. На Windows дополнительно запускается имитатор Discord через
Windows PowerShell: он проверяет обмен по отдельному named pipe, кириллицу,
разделённые пакеты, ping/pong, переподключение, смену ID и закрытие.
Настоящий Discord для этих тестов не используется.
Для отдельного тестового клиента: `.\gradlew.bat runClient`.

Если окружение Windows выдаёт `Unable to establish loopback connection`, можно
перед сборкой указать доступный каталог для временных Unix-domain сокетов Java:

```powershell
New-Item -ItemType Directory -Force .tools/tmp | Out-Null
$env:JAVA_TOOL_OPTIONS = "-Djdk.net.unixdomain.tmpdir=$((Resolve-Path .tools/tmp).Path)"
.\gradlew.bat build
```

Реализация использует [локальный Discord IPC](https://docs.discord.com/developers/topics/rpc)
без сторонних DLL. Разработано с помощью Codex.
