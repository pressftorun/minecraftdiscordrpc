# Проверка World Presence 1.4.0

Повторная проверка 15 октября 2026: просмотрены все исходники клиента,
настройки сборки, тесты и содержимое готового JAR. Новых подтверждённых
ошибок не обнаружено. Чистая сборка `clean build` на JDK 25 завершилась
успешно; все проверки выполнены заново.

Дополнительно проверены координаты у границы мира, ограничение длины строк,
ключ обложки `rpc_cover` в меню и мире, наличие иконки в JAR, а также
проверка Application ID: принятие, отклонение, ERROR, отсутствие Discord,
таймаут и отмена. Сообщение `Invalid client_id` в выводе тестов ожидаемо:
его намеренно возвращает имитатор для проверки обработки отказа.

Реальный игровой клиент и отображение в Discord в этой проверке не запускались.
Ниже сохранены результаты предыдущего аудита версии 1.1.1.

Исправлены найденные ошибки:

1. **Подключение к Discord:** Java преобразовывала прежний путь к named pipe в
   неверный путь. Ошибка воспроизведена локальным сервером, путь исправлен.
2. **Зависание при обмене и смене ID:** параллельные синхронные чтение, запись и
   закрытие одного Windows-канала блокировали друг друга. Подтверждено стеком
   JVM. Теперь канал обслуживает один фоновый поток без ожидания входящих данных.
3. **Сброс таймера:** временное отсутствие мира или игрока больше не считается
   выходом. Таймер привязан к событиям подключения и отключения.
4. **Пропавший биом:** длинный адрес сервера больше не занимает всю строку.
5. **Ввод ID:** длинная вставка не превращается незаметно в другой 20-значный ID;
   проверяется диапазон Discord snowflake.
6. **Сохранение настроек:** конфиг заменяется после успешной записи временного
   файла; ошибка записи не обнуляет существующий конфиг.
7. **Время суток:** устранено переполнение при экстремально большом числе тиков.

`gradlew.bat build` завершился успешно. Проверены форматирование, границы ID и
часов, сохранение конфига, ошибки сохранения и Windows IPC на отдельном локальном
имитаторе: handshake, разделённые пакеты, UTF-8, ping/pong, переход мир→меню,
повторное подключение, смена ID, закрытие. Имитатор не подключается к настоящему Discord.

Ограничения проверки: реальный Discord и визуальное поведение Mod Menu не
проверены. Предыдущий тестовый запуск Minecraft завершился нативной ошибкой
0xC0000005; её причина не установлена. Тесты не заменяют проверку готового JAR
в пользовательской сборке Minecraft.
