# World Presence — Fabric 1.21.11

Java 21, Fabric Loader 0.19.5+, Fabric API 0.141.6+1.21.11; Mod Menu 17.0.1 для настроек.

Скачайте world-presence-1.5.2+1.21.11-fabric.jar и положите в mods клиента, удалив предыдущую версию мода. Windows; на сервер мод не устанавливается.

Application ID задаётся в настройках мода или config/world-presence.json. Токены и Client Secret не нужны. Для картинки RPC загрузите assets/rpc-cover-paint.png в Discord Art Assets с именем rpc_cover.

Сборка и существующие тесты текста, конфига и Windows IPC прошли. Поведение в мире и отображение активности в настоящем Discord в рамках публикации не проверялись. Адрес сервера виден людям, которые видят активность Discord.
